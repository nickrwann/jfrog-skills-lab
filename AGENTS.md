# Repository instructions

This repository is a small learning environment for exploring JFrog
Artifactory Skills repositories.

- Keep the setup easy to understand, run locally, and remove.
- Prefer documented JFrog behavior and link primary documentation in the
  README when adding setup instructions.
- Never commit credentials, access tokens, licenses, or generated Artifactory
  data.
- Keep production-oriented complexity out of the repository unless it is
  clearly separated from the local learning setup.
